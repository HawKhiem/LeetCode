## 60. Permutation Sequence

The set `[1, 2, 3, ..., n]` contains a total of `n!` unique permutations.

Given `n` and `k`, return the `k`th permutation sequence of this set.

---

### Example 1:

**Input:**  
`n = 3, k = 3`

**Output:**  
`"213"`

---

### Example 2:

**Input:**  
`n = 4, k = 9`

**Output:**  
`"2314"`

---

### Example 3:

**Input:**  
`n = 3, k = 1`

**Output:**  
`"123"`

---

### Constraints:

- `1 <= n <= 9`
- `1 <= k <= n!`
